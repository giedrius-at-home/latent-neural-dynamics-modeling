## 3. Split problem & fix

### 3.1 Root cause
- Each session has 10-12 blocks × ~12 trials.
- **Every block is pure DBS-on OR pure DBS-off** (strict alternation).
- 60/10/30 → val = 10% = ~12 trials = exactly 1 block → **single-class val** for 2 of 4 cells (PDI4_S2 val all-off, PDI4_S3 val all-on).
- Classification during training / early stopping is broken on those cells.

### 3.2 New split: 60/15/45 (trial counts on 120-trial sessions)
- Fractions: `TRAIN=0.5, VAL=0.125, TEST=0.375`
- Verified class balance on actual data: every split has both DBS classes on all 4 cells.
- Val sizes 13-18 trials; test sizes 40-54.
- Defensible because PSID plateau at N=10 means shrinking train from 72→60 is free.
